    Foil packaging guide¶

    Step-by-step instructions for building and releasing a new DMG.

    Prerequisites (build machine)¶

    • macOS with Xcode 16+ and Command Line Tools
    • Homebrew with python@3.14
    • Cython 3+: ~/.foil/venv/bin/pip install cython setuptools wheel build
    • PyArmor: ~/.foil/venv/bin/pip install pyarmor (free tier, for .py obfuscation)
    • Node.js 22+ with npm
    • Code signing: Developer ID Application certificate (Vito Rallo, C4R94S6C7B)
    • Notarization: xcrun notarytool store-credentials foil-notarize --apple-id vito.rallo@gmail.com --team-id C4R94S6C7B
    • weasyprint system deps: brew install pango cairo

    Build command¶

    From the project root (/Users/vito/src/foil):

    # Full build + sign + DMG + notarize (always clean first)
rm -rf dist/xcode-build dist/Foil.app dist/Foil.dmg build
CREATE_DMG=1 NOTARIZE=1 bash scripts/build-release.sh

    Important: NEVER use SKIP_CYTHON=1 for release builds — it reuses old .so files that may have stale boundscheck settings or missing modules (e.g., license_guard.so).

    Options: - SKIP_CYTHON=1 — debug only, skip Cython recompilation - SKIP_WEBAPP=1 — skip Next.js rebuild (use when only Python/Swift changed) - CREATE_DMG=0 (default) — build app only, no DMG - NOTARIZE=0 (default) — skip Apple notarization

    What the build does¶

    Step What Output
    1 Cython compile .py → .so (boundscheck=True) dist/foil-cython/
    1b PyArmor obfuscate remaining .py files obfuscated .py in-place + runtime .so inside foil/
    2 Build foil wheel from Cython .so + PyArmor .py + runtime dist/wheel/foil-*.whl
    3 Build vllm-mlx wheel (from vendor/vllm-mlx/) dist/wheel/vllm_mlx-*.whl
    3b Download ALL dependency wheels recursively dist/wheel/*.whl (~65 wheels)
    4 Next.js static export webapp/out/
    5 Xcode Release build dist/xcode-build/.../Foil.app
    6 Bundle wheels + webapp + samples into .app Foil.app/Contents/Resources/
    7 Code sign all .so in wheels + app bundle Signed binaries
    8 Create DMG with Quick Start PDF dist/Foil.dmg
    9 Notarize + staple Apple-approved DMG

    Step 1b detail: PyArmor obfuscation¶

    PyArmor runs AFTER Cython and BEFORE wheel building. It obfuscates .py files that weren't Cython-compiled.

    How it works: 1. pyarmor gen --recursive -i -O dist/pyarmor-out dist/foil-cython/foil — obfuscates the entire foil/ package in one pass 2. Obfuscated .py files are copied back over originals in dist/foil-cython/foil/, but ONLY for files that don't have a corresponding .so (Cython-compiled files are skipped) 3. PyArmor generates a runtime package (pyarmor_runtime_NNNNNN/) containing a native .so — this is copied INSIDE foil/ because the obfuscated code uses relative imports (from .pyarmor_runtime_NNNNNN import __pyarmor__) 4. The wheel's artifacts = ["foil/**/*.so"] glob includes both Cython .so files and the PyArmor runtime .so

    Key flags: - --recursive — process all subdirectories - -i — package mode (preserves module exports — WITHOUT this, obfuscated modules export nothing) - -O — output directory (don't modify source in-place)

    PyArmor license: Basic license registered to "foil" product (license no. pyarmor-vax-012157). Registration file: pyarmor-regfile-12157.zip (backed up). Register on new machines with: pyarmor reg pyarmor-regfile-12157.zip

    What gets obfuscated (~37 files): - cli/*.py — CLI commands (split into 6 modules, all under 32KB) - server/routes/*.py — FastAPI route handlers - scanner_v2/language/*.py — framework-specific parsers - Top-level .py files not compiled by Cython (schema, config, etc.)

    What does NOT get obfuscated: - __init__.py files — PyArmor skips these by default - Any .py with a corresponding Cython .so — skipped by the build script

    Expected DMG size¶

    ~100 MB. The DMG contains: - Swift binary (~2 MB) - ~65 dependency wheels including foil, vllm-mlx, mlx, tree-sitter (~95 MB) - Webapp static export (~2 MB) - Samples, icon, Quick Start PDF (~1 MB)

    IP protection layers¶

    Layer What's protected How
    Cython .so analyzer, code_map, prompts, LLM client, license_guard, db, auth Compiled to native ARM64 binary
    PyArmor CLI commands, route handlers, language helpers Obfuscated bytecode (free tier)
    Plain .py __init__.py files, config, schema Public interfaces, no IP

    What is NOT Cython-compiled (and why)¶

    • Route files (server/routes/*.py) — FastAPI decorators use PEP 563 annotations incompatible with Cython. Protected by PyArmor instead.
    • Language helpers (scanner_v2/language/*.py) — tree-sitter Node C pointers get invalidated between parse phases, causing SIGSEGV in compiled code. Protected by PyArmor instead.
    • CLI (cli/*.py) — split into 6 modules (<32KB each) for PyArmor compatibility. Protected by PyArmor.
    • __init__.py files — not obfuscated (PyArmor default). Contain only imports, no IP.

    Combined protection summary¶

    Every .py file in the wheel is either Cython-compiled OR PyArmor-obfuscated (except __init__.py). No readable source ships in the release.

    Dependency management¶

    Bundled wheels (offline install)¶

    All dependencies are downloaded during build (Step 3b) and bundled in the DMG. The setup wizard installs from bundled wheels first (--find-links), with PyPI as fallback for any missing transitive deps.

    Setup wizard install command:
pip install --find-links /path/to/wheels foil-0.2.4.whl vllm_mlx-0.2.7.whl

    Pinned versions¶

    The release wheel pins ALL direct dependencies to exact versions in scripts/build-release.sh. Transitive deps are resolved by pip download during build.

    To update pinned versions: 

    # Snapshot current working versions
~/.foil/venv/bin/pip freeze | grep -iE "tree-sitter|fastapi|pydantic|..." | sort
# Update the pinned versions in build-release.sh

    Critical sync rule¶

    The release wheel deps in build-release.sh MUST include every package from src/core/pyproject.toml (both [dependencies] and [project.optional-dependencies.server]). Missing deps = silent scan failures on fresh installs.

    vllm-mlx¶

    Our own fork at vendor/vllm-mlx/ (v0.2.7). Built from local source — NOT from PyPI. The wheel is py3-none-any (pure Python). Its deps (mlx, mlx-lm, tokenizers, etc.) are downloaded from PyPI during build.

    Note: vllm-mlx depends on mlx-vlm which pulls torch, gradio, opencv (~200MB). These are optional (multimodal, not used by Foil). The build script removes them after download.

    Cython settings¶

    setup_cython.py compiles IP-sensitive modules to .so:

    • boundscheck=True — prevents segfaults (was False, caused SIGSEGV on VMs and test Macs)
    • wraparound=True — negative indexing works correctly
    • identity.py IS compiled
    • Route files are NOT compiled (PEP 563)
    • Language helpers are NOT compiled (tree-sitter Node lifecycle)
    • license_guard.py IS compiled (enforces paid feature gates)

    Release workflow¶

    After a successful build:

    # 1. Get SHA256
NEW_SHA=$(shasum -a 256 dist/Foil.dmg | cut -d' ' -f1)

# 2. Upload to GitHub release
gh release delete v0.2.4-beta --repo vitorallo/foil-releases --yes
gh release create v0.2.4-beta dist/Foil.dmg \
  --repo vitorallo/foil-releases \
  --title "Foil v0.2.4-beta" \
  --prerelease \
  --notes "Release notes here"

# 3. Update brew cask
sed -i '' "s/sha256 \".*\"/sha256 \"$NEW_SHA\"/" homebrew-foil/Casks/foil.rb
git add homebrew-foil/Casks/foil.rb
git commit -m "chore: cask SHA for v0.2.4-beta"

# 4. Push to homebrew-foil repo
cd /tmp/homebrew-foil
cp /path/to/foil/homebrew-foil/Casks/foil.rb Casks/foil.rb
git add -A && git commit -m "v0.2.4-beta" && git push origin main

    Version bumping¶

    Update version in these files: - src/core/pyproject.toml → version = "X.Y.Z" - scripts/build-release.sh → the wheel's pyproject.toml version = "X.Y.Z" - homebrew-foil/Casks/foil.rb → version "X.Y.Z-beta"

    Testing on a fresh Mac¶

    brew install python@3.14
brew tap vitorallo/foil
brew install --cask foil
# Launch Foil from Applications
# Setup wizard: creates venv, installs from bundled wheels, downloads model
# Scan: foil scan ~/.foil/samples/python_vuln

    Deploy via SSH (for test machines)¶

    # Copy just the new wheel (no full reinstall needed)
scp dist/wheel/foil-*.whl test@192.168.64.3:/tmp/
ssh test@192.168.64.3 "~/.foil/venv/bin/pip install --force-reinstall --no-deps /tmp/foil-*.whl"

    Uninstall¶

    Homebrew (keeps data): 

    brew uninstall --cask foil

    Full removal: 

    brew uninstall --cask foil  # or: rm -rf /Applications/Foil.app
rm -rf ~/.foil
defaults delete be.peachstudio.foil

    Common issues¶

    Symptom Cause Fix
    Scan fails silently Missing dep in release wheel Add to build-release.sh deps list
    SIGSEGV in .so on test Mac Language helper compiled with Cython Already excluded from COMPILE_MODULES
    "Bad wheel filename" on install PyPI "foil" package conflict Wheel installed by exact path, not name
    Server crashes with identity segfault boundscheck=False (old) Already fixed (True globally)
    license_guard.so NOT found Used SKIP_CYTHON=1 Never skip Cython for release builds
    0 files obfuscated by PyArmor Wrong pyarmor flags or file too large Check pyarmor gen syntax, split large files
    Stale wheels from old build dist/xcode-build cached Always rm -rf dist/xcode-build build first
    Menu doesn't dismiss SwiftUI MenuBarExtra limitation Uses NSPanel.orderOut(nil) workaround
    setupComplete survives uninstall UserDefaults not in ~/.foil Cask uninstall deletes plist; app checks venv exists
